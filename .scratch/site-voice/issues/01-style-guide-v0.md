# 01: 《站点文风》v0

**What to build:** 写出站点正文共用的写作契约《站点文风》，让后面的改写者（人和代理）不用自己判断「什么叫不 AI」就能动手。读者是改写者，不是学习者：一页以内，每条规则带本站现文里的反例和改后的正例。

先读：`.scratch/site-voice/spec.md`（全部决定）、`GLOSSARY.md`（词汇：站点文风 / AI 味 / 硬规则 / 软规则 / 三连目录 / 导语 / 固定区块 / 派生改写）、`docs/adr/0001-派生时重写文风.md`。`docs/文风依据.md` 若已存在，每条规则旁注它的来源编号；若不存在，留位。

内容：
- 读者称呼统一「你」。
- 5 条硬规则，暂行数值：① 无三连目录（课程正文不得有「## 目标」；导语只说学完你能做什么）② 加粗 ≤ 4 处 / 千字，只给界面上要找的控件 / 节点名和每节不能漏的那一句 ③ 标题 ≤ 20 字（去掉「L4 · 」类路径前缀后计）④ 导语 ≤ 70 字 ⑤ 正文小节不与固定区块重名（验收清单、对照图、本课涉及、翻页器）。
- 6 条软规则：数字清单化命名；「X：Y」冒号标题与括号标题；破折号与箭头密度；口诀 / 俏皮话；表格反射；标题不列举内容。
- 计数口径写明：加粗只数正文 `**…**`，代码块与行内代码内不计，一对算一处；字数按 CJK 字符数。
- 反例从 `src/content/lessons/01-03-prompt-basics.md` 和 `00-01-setup.md` 里取（它们是加粗密度的双倍离群点）。
