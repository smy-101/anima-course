# 站点文风 v0

站点正文共用的写作契约。读者是改写者（人或代理），不是学习者。派生改写 `source/` 时事实、数值、结论照搬，说法按这里重写；`source/` 不动（ADR 0001）。

- 读者称呼一律「你」。反例（00-01）：「下一课我们不碰模板，自己从空白画布搭一遍」。正例：「下一课你不用模板，从空白画布自己搭一遍」。依据：§A1、§A5、§H6。
- 硬规则不看上下文就能判对错。带数值的三条（H2、H3、H4）在试点课 `01-03` 上校准后定下。全站内容按它通过。依据文档对这三条不给数。软规则要结合整篇读才能判断，不给数值。
- 计数口径：加粗只数正文 `**…**`，代码块与行内代码内不计，一对算一处；「千字」按 CJK 字符数；标题、导语的长度按字符数（含空格、英文与标点）；引号只查代码跨度之外的正文与 frontmatter 字符串值。
- 出处：00-01 = `src/content/lessons/00-01-setup.md`，01-03 = `src/content/lessons/01-03-prompt-basics.md`。「依据」指 `docs/文风依据.md` 的节与条（§F2 = F 表第 2 行，§A8 = A 节第 8 条，§H3 = H 节第 3 条）。

## 硬规则

**H1 无三连目录**：课程正文不得有「## 目标」小节；导语只说学完你能做什么。
反例（00-01）：标题「认识 Anima、装好 ComfyUI、出第一张图」，导语「Anima 是什么、三个版本怎么选、要下哪三个文件…」，`## 目标` 第三遍「目标是：知道 Anima 是什么、该用哪个版本、三个文件放在哪…」。
正例：删 `## 目标`，开头「这一课不追求出好图」并入「Anima 是什么」第一段；讲什么只在标题、导语各说一次，两处说法不同。依据：§F1、§A8。

**H2 加粗 ≤ 4 处 / 千字**：只给界面上要找的控件 / 节点名，和每节里那一句不能漏的话。
反例（01-03）：全课 70 处 / 3093 字 ≈ 22.6 / 千字；`## 目标` 里 `先讲**为什么**（机制），再讲**怎么写**（三种写法、七条硬规则、四段式），最后讲**怎么查**` 一句三处全是高亮。
正例：这句一处也不加粗。全课只留两类：控件名，如 00-01 的 `点**运行**`；每节那一句，如 01-03 的 `**这一段里每个词都是一个精确的标签，不是形容词**`。依据：§F2、§A7。口径比 Google 宽：Google 只给 UI 元素与 run-in 标题加粗。中文没有通行的斜体强调，着重号在网页上不可用，加粗是唯一可读的强调手段（§H3）。

**H3 标题 ≤ 20 字**：去掉「L4 · 」类路径前缀后的字符数。
反例（01-03）：「提示词基础：Anima 怎么读你的话、三种写法、七条硬规则」，29 字。
正例：「写 Anima 提示词」，11 字。依据：§C Google Headings、§E zh-style-guide（只撑形态）。

**H4 导语 ≤ 70 字**：按 frontmatter `summary` 的字符数计。
反例（01-03）：「先懂机制（双分词器、逗号后空格、0.6B 的“大脑”），再学三种写法与七条硬规则、四段式结构、按版本调整、陷阱标签；最后用 Tagger 把“看着像”变成“叫什么”。」83 字。
正例：「学完你能按 Anima 的机制写出标签版、自然语言版和混合版提示词，并用 Tagger 把参考图反推成标签。」依据：§A8、§A1。

**H5 正文小节不与固定区块重名**：验收清单、对照图、本课涉及、翻页器。
反例（01-03）：`## 验收` 与页面的验收清单重复，末尾「下一课」链接又与翻页器重复。
正例：删 `## 验收`；独有的提示（「写提示词前，对照标签字典里的“陷阱标签”过一遍」）并入验收清单条目或正文对应小节，下一课交给翻页器。依据：§F1（重复，间接）。

**H6 引号一律用 “ ”**：正文与 frontmatter 字符串值里不得出现 ASCII 直引号 `"`；代码跨度里不动。
反例（01-03）：导语里的 `"大脑"`、正文里的 `"看着像"` 是直引号，同页的 “注意力预算” 却是弯引号。
正例：“大脑”、“看着像”；全站一个体例。依据：§H1、§B（clreq、GB/T 15834、排版指北）。

## 软规则

**S1 不拿数字清单当名字**。反例（00-01）：`## 四条纪律（贯穿全部级别）`；（01-03）：`## 七条硬规则`。正例：`## 实验纪律`、`## 提示词规则`。依据：§F3、§H5。
**S2 标题不带冒号副题，不用括号补充**。反例（01-03）：`## 陷阱标签：这些"普通英文词"其实会定义整张图`、`### 第三段：通用标签（主体）`。正例：`## 陷阱标签`、`### 通用标签`。依据：§F4。
**S3 破折号与箭头要少**：破折号能换成逗号、句号就换；箭头留给代码块里的流程图，不进标题和句子。反例（01-03）：`### 双分词器 → 权重只有一半生效`、`` 两路分词器都设了 `max_length=99999999`——**提示词不会被截断**。 ``。正例：`### 权重只有一半生效`；「两路分词器都设了 `max_length=99999999`，提示词不会被截断。」依据：§F5。
**S4 不写口诀和俏皮话**，直接说事。反例（01-03）：`口诀：**像给一个只会看图说话的人写图注**——简单词、简单句、一个分句一个看得见的事实…`。正例：「写提示词用简单词、简单句，一个分句写一个看得见的事实，细节和角色名放在同一句里。」依据：§F6。
**S5 机制与流程写成散文**，表只用于并排对照和速查。反例（00-01）：`### 一张图是怎么生成的：六个阶段` 把流程做成三列表。正例：「出一张图的顺序：Unet加载器、加载CLIP、加载VAE 把权重读进显存，CLIP文本编码 把提示词编成向量，空Latent图像 给出噪声图，K采样器 逐步去噪，VAE解码 还原像素，保存图像 写盘并嵌入工作流。」依据：§F7。
**S6 标题说这课做什么，不列举内容**。反例（00-01）：`准备：认识 Anima、装好 ComfyUI、出第一张图`。正例：`装好 ComfyUI，出第一张图`。依据：§F3、§H5。
**S7 一句一个意思，超过 40 字就拆**。反例（01-03）：「Anima 是拆分模型里少见的“真懂句子”的模型，但它的规则和 SDXL / Illustrious 不一样：下划线要换成空格、画师名要加 `@`、权重 1.2 约等于没加。」一句 60 字装了三件事。正例：「Anima 真懂句子，在拆分模型里少见，但规则和 SDXL / Illustrious 不同。下划线换成空格，画师名前加 `@`，权重 1.2 约等于没加。」依据：§H2、§A3。

## 三条约定

- 加粗：H2 的两类之外一律不加粗，术语、关键词、表格里的写法名都不算，要强调就单独成句；控件 / 节点名照界面原文写（运行、问题、K采样器）。依据：§F2、§H3。
- 标题：课标题动词开头、说这课做什么，可带「L4 · 」类路径前缀（「L4 · 放大三路线」）；正文小节标题用名词短语（「机制」「陷阱标签」）。依据：§C Google Headings、§E zh-style-guide。
- 导语：一句话，主语「你」，说学完你能做什么；不复述小节名，不堆术语，不写背景。依据：§A8、§A1。
