# Anima × ComfyUI 学习笔记 — 索引与阅读指南

> 本目录是 Anima（`circlestone-labs/Anima`）+ ComfyUI 的学习资料集。四份主报告是**桌面调研**（调研时间见各文件开头），文中几十处写着"以实测为准"——数值都应以自己固定种子的出图为准，读完就该去跑图。
