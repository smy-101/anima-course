## 目标

LoRA 是挂在模型线上的"小补丁"：风格、角色、概念各一个，几十到一百多 MB。这一课只做三件事：把 LoRA 正确地串进 Anima 的管线、用忽略（`Ctrl+B`）看清每一个的贡献、按纪律定下强度。官方四个 LoRA 顺带认全，其中 `anima-highres-aesthetic-boost` 下一课放大就要用。

## 新增节点

| 节点 `类名` | 作用 | 关键参数 |
|---|---|---|
| LoRA加载器（仅模型）`LoraLoaderModelOnly`（L1 已见过，可再串多个） | 风格 / 角色 LoRA | `lora_name`、`strength_model` |
| 加载 LoRA（模型）[LoadLoraModel](/nodes/LoadLoraModel/)（LoRA 堆栈，可选） | 一个节点挂 1 ~ 20 个 LoRA，每行选文件、强度、开关 | 固定搭配一串 LoRA 的工作流用它更省地方 |

端口细节：[LoraLoaderModelOnly](/nodes/LoraLoaderModelOnly/) · [LoadLoraModel](/nodes/LoadLoraModel/) · [LoraLoader](/nodes/LoraLoader/)（Anima 不用，认识即可）

## 连线 C：LoRA 串联

```
UNETLoader.MODEL ──▶ LoraLoaderModelOnly①(风格 A, 0.8).MODEL ──▶ LoraLoaderModelOnly②(角色 B, 1.0).MODEL ──▶ KSampler.model
```

Anima 是拆分模型，**只用 LoRA加载器（仅模型）**：[加载LoRA](/nodes/LoraLoader/)`LoraLoader`（同时影响模型和文本编码器）的 `clip` 输入是必填，没接 CLIP 会报"缺少输入"。LoRA 加载器只有 `model` 进 `MODEL` 出，所以可以无限串联，最后一个的输出接 K采样器（在 L1 里则是接在 UNETLoader 与 Turbo 开关之间）。

A/B 某个 LoRA：选中它按 `Ctrl+B`（忽略 = 不执行但数据透传），下游拿到的是上游的 MODEL，工作流照常运行。`Ctrl+M`（禁用）会让下游断粮报错，别用它做对比。

## 四个官方 LoRA

| 官方 LoRA（`circlestone-labs/Anima-Official-LoRAs`） | 用法 | 作者说明 |
|---|---|---|
| `anima-turbo-lora-v0.1 / v0.2` | CFG 1、8–12 步；`strength` 0.7 ~ 1.0 | v0.2 在 base-v1.0 上训练，"细节更自然"；降到 0.7 仍保持蒸馏；用 `euler`，`er_sde` 可能太吵 |
| `anima-highres-aesthetic-boost` | 出高分辨率时挂上，`strength` 1.0 | 1536 基本无问题，甚至 2048（4 MP）也不散架；美学提升"较弱、看提示词"；v1.0 版说明写的是在 preview3 上训练 |
| `anima-rl-v0.1` | 默认 1.0；配强的美学微调模型时可能要略高于 1 | 强化美学与细节的 RL 实验版；在 preview3 上训练 |
| `anima-greg-rutkowski-style` | 提示词前缀 `@greg rutkowski. `，自然语言提示词效果最好 | 风格 LoRA 示例，附带训练配置 |

模型清单见[模型文件清单](/resources/model-files/)。两个在 preview3 上训练的 LoRA 用在 v1.0 上效果可能打折扣——以自己的对照图为准。

## 参数与取值（起点值）

| 强度 | 经验 |
|---|---|
| 风格 LoRA | 0.6 ~ 1.0（Civitai 官方接口给的典型范围） |
| 角色 / 概念 LoRA | 偏高，1.0 起 |
| 训练于 Base 的 LoRA 用在 Aesthetic 上 | 可能被"稀释"，必要时略升强度 |
| 两个 LoRA 风格互相打架 | 降其中一个到 0.6 ~ 0.7，或分两段采样各挂一个（上一课的方式 2：第一段挂 A，第二段挂 B） |

## 动手步骤

1. 从 Civitai 或 HF 下两个标注"兼容 Anima"的 LoRA（一个风格、一个角色），放 `ComfyUI/models/loras/`，按 `R`。
2. 在 L3 工作流的 UNETLoader 之后串两个 LoRA加载器（仅模型），风格 0.8、角色 1.0。文件下拉里没有就按 `R`。
3. 固定 seed、固定提示词，跑四张：都不挂（两个都 `Ctrl+B`）、只挂 A、只挂 B、都挂。每张前面接一个绘制文本叠加 写明组合，进图像表格。
4. 对风格 LoRA 做强度扫描：0.6 / 0.8 / 1.0 → 创建列表 → 接 `strength_model`（拖成输入口）。
5. 换成 Aesthetic 整模型重复第 4 步，看强度是否需要上调。

## 调参顺序

**先单独挂，再叠加**：每个 LoRA 单独出一张看它做了什么，再两个一起挂看是否打架。强度用 T3 的"先粗后细"：0.6 / 0.8 / 1.0 粗扫，再 0.05 步长细扫。每个 LoRA 的贡献都靠 `Ctrl+B` 对照得出，不靠感觉。

## 常见问题

| 现象 | 原因 / 处理 |
|---|---|
| LoRA 没效果 | 文件是否标注"兼容 Anima"；放好后是否按了 `R`；强度是否太低；用的整模型是否与 LoRA 训练底模差太远（preview3 → v1.0） |
| 两个 LoRA 风格互相打架 | 降其中一个到 0.6 ~ 0.7，或分两段采样各挂一个 |
| 角色 LoRA 把整张图都带偏 | 角色特征太强：强度降到 0.8，或把角色描述也写进提示词分担 |
| 挂 LoRA 后出图变糊 / 过饱和 | 先 `Ctrl+B` 确认是这个 LoRA 的问题，再降强度或换采样器 |
