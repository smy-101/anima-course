## 复盘

六天下来，L1 的工作流你已经复制了好几份。L2 在上面扫参数，L3 在上面接图生图和 LoRA。每次都从 19 个节点开始改，既乱又容易漏线。今天不学新节点，只做两件整理工作。先把参数基线写成一张便签，再把管线收成一个可复用的节点。做完之后，阶段 4 和 5 的每个工作流都从“拖一个节点”开始。

|---|---|---|---|---|---|---|
| Day 4 | base-v1.0 | er_sde / simple | 4.0 | 30 | 1 | cfg 3.5 偏淡，4.5 线条发硬 |
| Day 5 | aesthetic-v1.1 | euler / simple | 4.0 | 30 | 0.4 | Turbo 味重时 denoise 升到 0.5 |
| Day 6 | aesthetic + 风格 LoRA 0.8 | euler / simple | 4.0 | 30 | — | 角色 LoRA 1.0 会带偏背景，降到 0.8 |

再回答三个复盘问题，按周问一遍：① 这周哪张最好、为什么；② 学到的“不要这样做”有几条；③ 下周（阶段 4）要验证的假设是什么。答案写进便签，和子图一起保存。

## 子图

子图可以理解为工作流的“文件夹”：把相关节点分组，整个集合当作一个节点使用。前端版本要在 1.24.3 以上。

| 操作 | 怎么做 |
|---|---|
| 创建 | 选中节点，点工具箱的**子图图标**。ComfyUI 按选中节点的输入输出自动生成子图 |
| 编辑 | 双击子图上非控件的空白处进入；顶部导航栏或 `Esc` 退回上一级 |
| 输入 / 输出插槽 | 子图编辑态顶部有插槽栏。把外部输出连到输入插槽，就能从外面给内部节点传值；在插槽上右键可重命名 / 删除。默认插槽用来新增连接并暴露给上级 |
| 控件 | 内部节点的控件会显示在子图节点上。选中子图，点**编辑子图控件**打开参数面板（v0.3.66+），拖动排序、点眼睛图标决定哪些显示 |
| 状态 | 和普通节点一样：改色、改名、`Ctrl+B` 忽略；可以嵌套 |
| 转回普通节点 | 选中子图，再点一次同一个按钮（右键菜单里也有） |
| 发布 | 前端 ≥ 1.27.7：选择工具箱的书本（发布）图标，点**添加子图到库**。默认用子图名，可改；发布后节点库里就有这个“蓝图” |

从蓝图拖出来的新子图节点**相互独立，要改蓝图本身，去节点库里改**。在节点库里点它的编辑按钮进去改，`Ctrl+S` 保存。

官方 Anima 模板就是这样做的。画布上只有子图、分辨率选择器、保存节点和便签，双击进去才是 17 个节点。它的子图对外暴露 `text`（正向）、`text_1`（负向）、`width` / `height`、`seed`、`unet_name` / `clip_name` / `vae_name`、`value`（Turbo 开关）和 `lora_name`。照着这份清单整理，你的子图就和官方的用法一致。

## 动手步骤

1. 打开 L1 的工作流（19 个节点、Turbo 开关、分辨率选择器驱动尺寸的那版），`Ctrl+S` 另存为 `L1_subgraph`。
2. 框选从 UNETLoader 到 VAEDecode 的全部节点（不含分辨率选择器、保存图像），收成子图，命名 `Anima T2T`。
3. 退出来，把分辨率选择器的 width / height 连到子图的输入插槽，对齐空Latent图像的 width / height。选中子图，点编辑子图控件：留下正负提示词、seed、Turbo 开关、三个模型名和 Turbo LoRA 名。其余控件（steps / cfg / 采样器）先隐藏。
4. 在子图旁边加一张 Markdown 便签，写上当前参数基线表、四条纪律和文件放哪。选中子图，点书本（发布）图标，选添加子图到库，命名 `Anima T2T`。
5. 新建空白工作流，从节点库拖出 `Anima T2T`，接分辨率选择器与保存图像，出一张图确认能跑。
6. 以后 L3 的图生图、L4 的放大，都在这个子图的基础上“插入”或“追加”节点。双击进子图里改，或者在子图外面接。

## 参数与取值

子图本身没有参数。它的“参数”就是你在参数面板里留下来的那些控件的默认值。把基线值设成默认，Full 30 步 / CFG 4，Turbo 8 步 / CFG 1，拖出来就能跑。

## 常见问题

| 现象 | 原因 / 处理 |
|---|---|
| 子图节点上看不到某个控件 | 参数面板里把它隐藏了，或它属于没被收进子图的节点；双击进去确认 |
| 拖出来的子图缺模型 / 变红 | 模型名控件的默认值指向你机器上不存在的文件；在子图节点上重新选 |
| 子图里的 `turbo_mode` 开关在外面没反应 | 三个切换节点的 `switch` 没接到同一个布尔值；进子图检查 |
| 改了一份蓝图副本，别的工作流没跟着变 | 正常，蓝图拖出来的副本相互独立。要统一更新就改节点库里的蓝图再重新拖 |
| 找不到“添加子图到库” | 前端版本低于 1.27.7，更新 ComfyUI |
