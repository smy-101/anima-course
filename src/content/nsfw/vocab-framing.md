这一组描述的是**画面的构图与时间点**——谁在展示、发生在之前还是之后——而不是具体行为。它们大多落在 `sensitive`～`nsfw` 级别；等级仍按画面里最露骨的元素判断（见[安全等级](/nsfw/safety-rules/)）。

## 展示

| 标签 | 含义 |
|---|---|
| `presenting own body` | 展示自己身体：以性暗示方式露出或强调身体某部位，常是邀请或挑逗 |
| `presenting own pussy` / `presenting own ass` / `presenting own anus` / `presenting own breasts` / `presenting own arm` / `presenting own armpit` / `presenting own foot` | 展示各部位 |
| `presenting another's body` | 展示别人（第三方视角） |
| `take your pick` | 多个角色一起展示供挑选 |

## 之前 / 之后

| 标签 | 含义 |
|---|---|
| `imminent penetration` | 即将插入：还没插入但马上就要。只用于裸体；穿衣用 `dry humping` / `bulge to ass` |
| `imminent vaginal` / `imminent anal` | 即将阴道插入 / 肛门插入 |
| `guided penetration` / `just the tip` | 用手引导插入 / 只进去一点 |
| `implied sex` | 暗示发生了性行为（画面本身可能不露骨） |
| `after sex` / `after vaginal` / `after anal` / `after fellatio` / `after paizuri` | 各类事后 |
| `clothed after sex` | 穿衣事后 |
| `afterglow` | 事后余韵表情（见[表情](/nsfw/vocab-body-clothing/)） |

## 怎么用

- 这一组标签决定的是**镜头停在哪个瞬间**。同一对角色，`imminent penetration`、`implied sex`、`after sex` 是三张完全不同的构图；先用它们定构图，再写人物。
- 多人展示（`take your pick`、`presenting own body` 多人）同样受标签传染影响：每个角色的特征都要单独写完整，见主线的[多人与传染](/lessons/02-02-prompt-multi/)。
- `presenting own …` 系列会把镜头拉向所展示的部位，与构图标签（`full body` / `upper body` / `from below`）一起用效果更可控，见[标签字典](/tags/)。
