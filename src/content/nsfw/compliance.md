| 事项 | 说明 |
|---|---|
| 模型许可 | CircleStone Labs 非商业许可：**模型和衍生权重**只能非商业；**生成的图片可以商用**（卖图、约稿、商业项目概念图）。不可：收费 API、付费平台、嵌入收费产品。作为 Cosmos 的衍生模型还要遵守 NVIDIA Open Model License |
| NSFW 内容的法律边界 | 各国对色情内容（尤其涉及未成年人、非自愿、人兽、极端暴力）的法律不同，用户自行负责。**`loli` / `shota` 等性化未成年人的标签在任何情况下都不应使用**（多数司法辖区违法 + 违反各平台规则） |
| 平台规则 | Civitai、TensorArt、mage、KusArt、IMGNAI 等托管平台各有审核规则；本地生成不受平台约束但受法律约束 |
| 画师标签 | 用 `@画师` 模仿在世画师风格存在伦理与版权争议；日本文化厅意见：画风本身不受版权保护，但 LoRA 文件和使用 LoRA 生成的图片**可能**构成侵权（dskjal 引用） |
| 数据集来源 | 主数据集 Gelbooru 抓取自各画师作品；用于学习的合法性在日本法下有"信息解析"例外条款，其它法域不同 |

本附录对极端标签只做识别、不给用法；示例图一律不收录。
